# ISLAND 聚焦性能优化验证

测试环境：Apple M4，Chromium / ANGLE Metal，本地既有 localhost:3000 开发服务。桌面视口 3840×2160，deviceScaleFactor=2。

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 3D 画布尺寸 | 5760×3240 | 2730×1536 |
| 3D 像素数 | 18,662,400 | 4,193,280 |
| 第一轮 GPU 平均耗时 | 35.44 ms | 9.90 ms |
| 第二轮 GPU 平均耗时 | 39.40 ms | 9.64 ms |
| 两轮平均 | 37.42 ms | 9.77 ms |
| 首次聚焦创建新程序 | 16 | 0 |

GPU 平均耗时减少 73.9%。通过 EXT_disjoint_timer_query_webgl2 测量 GPU 执行时间，每组预跑 4 帧、采样 40 帧，35 ms 间隔，顺序为优化前→优化后→优化前→优化后。两轮均无页面异常。该结果是测试硬件上的场景绘制时间，不等同于用户浏览器帧率。

首次聚焦原有约 1.5 s 的同步编译阻塞已移至开放交互前异步预热；最终版本的首次聚焦未发生新程序创建或长任务，记录的最长单次 CPU 绘制为 3 ms。

## 实现

- 默认直绘、聚焦离屏绘制、景深程序分别异步预编译，并预先完成纹理与离屏目标初始化。
- 设置 4,194,304 像素上限；普通视口继续使用原 DPR，DOM 菜单与导航仍按原生分辨率显示。大屏 3D 图像会降低超采样精度。
- 保留原九采样景深，清晰区域跳过额外采样，保留地面与地平线清晰度；半分辨率三次绘制方案实测更慢，未采用。
- 仅在镜头、建筑位置或尺寸变化时更新投影点击轮廓，缓存指针边界，避免重复布局读取。
- 星盘模糊直接更新目标节点，避免逐帧修改 body 上的继承变量。
- 透明且无贡献的圣光不绘制；静止和后台继续停止绘制。
- 预热途中离场先停止交互与绘制，等待 Three 编译轮询结束后释放 GPU 资源。

## 验证

- 全部四分类聚焦、切换、空白退出、头部冻结、悬停、子菜单路由与主题回归通过。
- 四分类连续切换无新着色器链接或纹理分配；静止无新绘制。
- 4K 像素预算通过，预热途中离场无异常且程序资源实际删除。
- 桌面与移动端离场几何、滚动恢复通过。
- vue-tsc、ESLint、Prettier、git diff --check 与 Vite 生产构建通过。
- 两个旧用例更新为等待场景预热就绪后再检查，不改变几何和缓存断言。

原始数据：temple-final-ab.json；复测脚本：temple-final-benchmark.mjs。场景与资产未替换。

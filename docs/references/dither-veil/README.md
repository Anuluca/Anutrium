# Dither Veil 封面适配

- 上游：[Vue Bits DitherVeil.vue](https://github.com/DavidHDev/vue-bits/blob/main/src/content/Animations/DitherVeil/DitherVeil.vue)。许可保留于同目录 `LICENSE.md`。
- 详情封面使用上游 Bayer 8×8 阈值排列，SVG 滤镜按 RGB 分通道四级抖色，保留原图色彩；直接作用于封面图片，不读取跨域像素。抖色网格与图片共同移动，入场和滚动位移均作用于带滤镜的图片整体。
- 鼠标／触屏按住封面时，以柔边局部显露原图，松开或离开后用 0.8 秒恢复抖色；减少动态效果模式即时切换。监听所属弹窗且保持被动，正文点击、滚动沿用原有逻辑。
- 原图层和抖色层共用同一线上缩略图、入场动画、裁切与滚动位移。未引入 WebGL 依赖或常驻渲染循环。

- 封面加载完成后，背景模块连同滤镜用 1.2 秒渐显入场；加载期间保持不可见，减少动态效果模式直接显示。渐显不改变原有标题入场、背景位置和滚动位移。

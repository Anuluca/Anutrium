# Floratrium 与共享页面布局审查

- 日期：2026-10-22（Asia/Shanghai）。
- 范围：`TemplePage`、Floratrium 信息／战力／招式／媒体模块、共享 Layout、相关组合式函数、媒体分页及模型生命周期。
- 原则：沿用当前构图、组件、主题、动画顺序、线上 R2 地址及弹窗规范；按实际调用频率优化。

## 1. 删除与去重

| 项目 | 处理 |
| --- | --- |
| 相册与视频重复的遮罩参数、展开／收起、空白点击过滤、通知逻辑 | 提取 `useFloraMediaPanel`，保留各自网络请求、分页和媒体释放逻辑。 |

| 两处 import 排序 | 修正相册及宠物相机模块的导入格式。 |

- 没有发现可确认无引用、能够安全删除的业务文件，未按文件名或表面相似性删除模块。

## 2. 算法与运行开销

| 路径 | 修改前 | 修改后 |
| --- | --- | --- |
| 图片就绪事件验证 URL | 每次 `includes` 遍历当前列表；N 张照片整批最坏 O(N²) | computed Set 只随列表重建，单次平均 O(1)，整批 O(N)。 |
| 精选相册动画重建 | 每张卡片分别生成相同采样点、排序、关键帧对象 | 每次重建只计算一份关键帧数组，由全部动画使用。10 张照片的测试确认每次只有 1 份数组，而非 10 份。 |
| 重复 ResizeObserver 通知 | 即使宽高不变，也取消并重建全部动画 | 宽高和内容均未变化时复用动画；内容和减少动态效果设置变化时仍重新构建。 |
| About 遮住相册 | 相册未接入页面活动状态；`display: none` 产生的零尺寸还会触发动画重建 | 复用 `useDecorationActivity` 暂停动画；零尺寸不重建，恢复相同尺寸后继续原动画。测试验证暂停期间时间不变，并复用原实例。 |
| 相册卸载、路由离场固定边界 | 对每个节点交替读取与写入样式 | 先批量读取，再批量写入，减少强制同步布局机会。 |
| 资料尺寸拟合 | 字体、尺寸和内容事件分别取消／重排下一帧；字体读取之间夹有样式写入 | `useFrameTask` 合并同一帧任务；先读取两个字体，再写入固定字号。 |
| 字体就绪晚于组件卸载 | 延迟回调仍可能安排测量 | `useFrameTask` 在作用域销毁后拒绝新任务；相册也检查卸载状态。 |

- 保留资料区基于真实换行高度的二分拟合；未用简单缩放比例替换，以免破坏容器单位与换行布局。
- 两只宠物、六个战力轴属于小数组，不为这些低频操作强行增加 Map。
- 既有媒体分页已按访问页请求，R2 键名索引已缓存；未重复实施已有优化，也未发现本轮需要修改的 N+1 请求路径。
- 以上收益是分配／调用次数和浏览器行为验证，不是生产环境耗时或帧率提升百分比。

## 3. 结构与布局

| 文件 | 职责 |
| --- | --- |
| `src/layout/useRouteShellGeometry.ts` | 路由离场边界保护、Shell 类保留、路由守卫、超时兜底和清理。 |
| `src/views/Home/composables/useFloraProfileFit.ts` | 资料区按可用高度拟合、字体与尺寸监听。 |
| `src/views/Home/composables/useFloraMediaPanel.ts` | 媒体面板共用交互和扫描线遮罩。 |
| `src/views/Home/composables/useFloraMoveNameFit.ts` | 仅在手机端招式名称超宽时缩小文字，合并四张卡片的测量与写入。 |
| `src/views/Home/styles/floraFocusLayout.less` | 聚焦布局样式；从组件原样迁移，内容逐字比对一致。 |

- `FloraFocusLayout.vue` 从本轮开始时的 1427 行缩至 559 行，模板和布局样式分开维护；不把迁移行数当作代码删除量。
- 共享 Layout 的路由几何逻辑从入口组件中独立，布局入口只负责调用和提交页面状态。
- 战力图与招式动画延迟改为根据 CSS 时长变量计算，避免以后调整一个时长却遗漏后续延迟；当前动画节奏保持一致。
- 修复手机端招式名称与属性标签重叠：只缩小实际溢出的名称，保持卡片、属性与 PP 的布局。
- 路由 Shell 类仍在离场完成、取消或超时兜底后清理。

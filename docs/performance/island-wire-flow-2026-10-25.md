# Island 网格光电流动：源码依据与验证

## 参考源码

- 获取时间：2026-10-25。
- 入口：[yutaabe.com](https://yutaabe.com/)。
- 公开脚本：[index.DTZ4osvG.js](https://yutaabe.com/_astro/index.DTZ4osvG.js)，由 Layout 脚本导入。
- SHA-256：`9b1628005bd35f3885d72a44fbfb5bca01317626724c04bfe2b00dd1e27c47c6`。
- 定位：`tn` 片元着色器中的 `travel1/2/3`、`pulse1/2/3`、`travelLight`；本次基于实际脚本分析。

| 分量 | 空间相位 | 时间速度 | 叠加权重 |
| --- | --- | --- | --- |
| 纵向 | view.y × 4 | −0.6 | 1 |
| 横向 | view.x × 3 | +0.5 | 0.7 |
| 斜向 | (view.x + view.y) × 3.5 | −0.7 | 0.5 |

- 每组通过 `fract` 循环，对三角形波取 12 次方，形成窄光点。
- 三组叠加后乘网格遮罩与已转换区域遮罩，光电仅出现在线条上。
- 原始光电颜色为 `(0.6, 0.8, 1.0)`，强度系数 `2.5`。
- 参考站另有材质切换扫描边界、点阵光照和入场效果，这些不属于持续网格光电。

## 本项目适配

- 删除上一版自行设计的单一宽亮带、正弦闪光及面内光晕。
- 在现有合成材质中使用上述三组脉冲参数、权重、指数、颜色和强度。
- 使用变形后的真实视空间坐标，按原站实际模型世界高度换算：cat.glb 的 POSITION.y 范围为 −0.457629323 至 0.493206799，乘桌面 `_catScale = 4.5` 得到 4.27876255；移动端按原站 `_catScale = 2.4` 换算为 2.28200669；已撤销未经源码依据的两单位归一。
- 保留本站主题色底线、抗锯齿像素线宽、扫描转换与头部变形；底线亮度借鉴原站漫反射和高光计算，本站将上限设为 0.45 以保留暗色主题线并突出浅蓝白光点；光电按原片元着色器直接输出，不额外套用 sRGB 转换。
- 复用同一材质与绘制通道，无新增模型、贴图、后处理或逐帧顶点修改。
- 可见网格持续绘制，上限沿用 60fps；后台或遮挡暂停；返回首页恢复按需绘制；减少动态效果时光电静止。

## 验证

- 桌面及 Pixel 7 模拟视口测试覆盖动画变化、GPU 顶点/纹理/程序资源稳定、隐藏暂停、恢复、退出停止及减少动态效果。
- 独立 GPU 像素测试：隔离真实网格材质，分别在三个时刻读回像素，检查亮点移动且没有超出线条进入三角面内部。
- 原有扫描、缩放及回程回归覆盖桌面和移动布局。
- 帧间隔采用本机 Chrome 的 120 个 requestAnimationFrame 样本；不能等同移动真机性能或 GPU 执行时间。
- 测试配置 `playwright.flow.config.ts` 仅复用 localhost:3000，禁止自动启动或停止服务。

## 最新实测

- 修正模型尺度和输出色彩后，桌面动画、后台暂停/恢复、退出停止、减少动态效果及独立像素测试通过。
- 独立像素检查：三个时刻共 8200 个亮点像素采样，网格线外亮点像素为 0，前两个时刻有 1280 个亮点像素移位。
- 桌面 requestAnimationFrame 中位数及 P95 均约 16.7ms；不代表真机 GPU 基准。
- 已有两处类型错误仍位于 `WorkCard/index.vue:102` 与 `Craft/CraftContent.vue:91`，本次没有修改这些文件。
- 最终桌面与移动模拟共 6 项流光专项测试通过；录屏采样帧间隔中位数 16.7ms、P95 16.8ms。
- 实际页面录像：`/tmp/island-electric-flow-desktop.webm`、`/tmp/island-electric-flow-mobile.webm`，含可见动画、隐藏暂停和返回首页停止。

# Island 光电实现性能优化

## 范围与行为

仅优化现有网格光电及其持续渲染路径，不改变颜色、强度、间距、速度、沿线高亮范围、扫描转换或鼠标跟随。

## 改动

1. `templeScene.ts`：区分内容失效 `invalidate()` 与继续调度 `scheduleFrame()`。模型、镜头和环境静止后，只推进光电 uniform 并绘制；省去隐藏环境更新、矩阵/批次更新、姿态阻尼和锚点投影。指针、主题、尺寸、路由等事件仍触发完整更新。
2. `drawScene(updateComposition)`：将构图更新与提交绘制解耦。稳定光电沿用已有灯光、矩阵、渲染队列和实例缓冲。
3. 诊断发布修正：光电仍在动画时不再被当作整页静止，每帧重复发布诊断；沿用已有 100ms 间隔。
4. `modelScan.ts`：三组仿射相位由片元阶段移到顶点阶段；`fract` 留在片元，避免周期接缝。无网格线/尚未转换的区域直接跳过脉冲计算。
5. 删除重复的三组标量脉冲表达式及仅用于计算的中间变量；用向量运算和共享乘积求 12 次方，预合并固定配色/强度常量。未发现可安全删除的独立生产文件，未新增依赖。
6. 集中管理光电时钟，按三组速度的共同周期 20 秒取模，避免长期开页后浮点精度持续下降。

## 本机 CPU 抽样

关闭内部诊断，稳定后采集约 2.4 秒。仅统计实际发生 WebGL 绘制的场景 RAF 回调，排除 60fps 上限产生的空回调。这里测量的是 CPU 提交与场景计算耗时，不是 GPU 执行耗时。

| 布局 | 优化前平均 / P95 | 优化后两轮平均范围 | 优化后 P95 范围 |
| --- | --- | --- | --- |
| 桌面 Chrome | 0.466 / 0.800 ms | 0.154–0.286 ms | 0.300–0.500 ms |
| Pixel 7 模拟视口 | 0.488 / 0.800 ms | 0.241–0.278 ms | 0.400–0.500 ms |

- 每轮约 143–145 个实际绘制帧；机器并非独占运行，结果有波动。
- 移动模拟采用本机 CPU/GPU，不能替代移动真机基准。
- 当前无专用 DevTools 性能追踪工具；不据此宣称 Core Web Vitals 或 GPU 耗时提升。

## 验证

- 流光专项测试覆盖桌面/移动布局的动画、资源稳定、隐藏暂停、恢复、退出停止及减少动态效果。
- 独立 GPU 像素检查：亮点仍只出现在线条上；20 秒时钟周期回绕前后的等价画面像素最大差为 0。
- 生产路径 CPU 采样在内部诊断关闭时运行，并验证鼠标移动后模型连线锚点继续变化。
- 使用已有扫描、回程、锚点重排及合成材质测试验证交互和几何。
- 配置仅复用 localhost:3000，测试输出写入独立 `/tmp/anutrium-flow-*` 目录。
- 修改文件 ESLint 通过；全项目类型检查仍被 `WorkCard/index.vue:102`、`Craft/CraftContent.vue:91` 两处已有参数类型错误阻塞。

### 已有失败的隔离结果

- 扩展回归中，`model-scan-composite.spec.ts` 的 indexed/expanded 形变像素一致性断言失败：扫描进度 0.25、头部角度 0 时有 305 个差异像素，最大通道差 254。
- 将光电着色器换回本次优化前的三组标量 `pow` 实现后，仍复现完全相同的差异。已保留原断言，没有扩大容差；临时隔离文件已删除。
- 桌面/移动独立重跑均复现此断言失败；合并回归的移动 worker 另发生停止响应，超过五分钟后终止了本次测试进程。没有操作用户开发服务。
- 其余 8 项扩展回归通过，覆盖锚点更新、重排/聚焦切换、扫描运镜回程及合成透明度/深度端点。
- 最终结果：8 项光电专项（含生产路径 CPU/鼠标唤醒）通过；8 项扫描/锚点/基础合成扩展测试通过；1 项首次聚焦着色器和纹理复用测试通过。另有 2 项既有 indexed/expanded 像素断言失败，隔离结果如上。

## 首页与非 ISLAND 模块的后续优化

- 核对现状：这些状态原本已隐藏中央光电网格，不因光电持续渲染；其他模型的普通线框材质也不含光电脉冲。
- 光电开关显式绑定中央 ISLAND 选择态；进入其他模块立即关闭顶点相位、片元脉冲和时钟推进。原扫描转换亮边保留。
- 首页及其他模块的中央实体无扫描时，跳过扫描坐标归一化和扫描裁切距离分支。
- 保留同一预热程序，通过 uniform 开关控制，不引入切换时的材质重编译。
- 此改动的收益主要在指针跟随、主题变化和模块切换所需的重绘中；稳定静止页面原本已经没有光电持续绘制负载。
- 隔离验证时固定 `lucarioHeadache=false`，排除服务端控制的独立贴纸动画；正常产品中保留此动画。
- 新增实测检查覆盖初始首页、ISLAND、FLANERIE、ARCHIVE、CREATIVE、POKEYARD、FLORATRIUM：只有 ISLAND 持续推进光电，其余状态在交互阻尼收敛后停止场景绘制。
- 独立 GPU 检查确认光电关闭时，测试材质的光电颜色通道最大值为 0。
- 此轮验证：桌面/移动全模块停绘检查 2 项通过，光电关闭的像素检查 2 项通过，扫描回程 2 项与桌面材质预热复用 1 项通过；移动预热测试按既有设置跳过。修改文件 ESLint 通过。

# 首页 A5：限制真实聚光灯数量

日期：2026-10-24。对应 [3D 审计 A5](../research/3d-performance-audit-2026-10-24.md)。本轮建立在 A4/A6/A7 和倒影提亮之后；原性能记录的源码指纹保留为历史快照。

## 实现

- 四柱及宠物的五个 SpotLight 仅作为位置、颜色、光束参数和动画强度的控制对象，不再挂入 Scene。
- `scene/spotLightPool.ts` 提供两个真实 SpotLight 槽位。稳定总览且没有宠物悬停时为 0 盏，普通聚焦为 1 盏，交接时最多 2 盏；强度为零的槽位关闭可见性，不进入 Three.js 的光照收集。
- 保留被选中来源的位置、目标、颜色、强度、距离、锥角、半影和衰减，已有光幕、光池和主视觉 PointLight 不变。
- 快速连续切换可能同时留下超过两路衰减尾巴：仅保留最强的两路。强度 ≤ 0.0001 的尾数不占槽；普通两路交接不截断。
- 槽位尽量保持原来源，避免无意义交换。每帧仅复制状态并更新已有矩阵，不创建新灯、几何或纹理；灯光变化使首页静态缓存失效。
- 实际灯及 target 纳入已有矩阵更新器；控制灯仍参加主题染色，卸载释放灯池，预热期间离场继续等待编译结束后释放渲染器。

## 变体预热与成本

- 加载阶段预热 0/1/2 灯及不透明/半透明队列。主要为 Standard/Physical 编译灯数变体，避免为无光照 Basic、Sprite 复制三套等价程序。
- 所用本地 Three.js 的 `compileAsync()` 不逐对象建立局部裁切状态；Line 虽不执行物理光照，程序缓存键仍包含灯数。按材质实际 0/1 个裁切面分组，通过初始化阶段空场景声明同数量裁切槽位，预热真实的灯数/裁切组合，避免错误的零裁切程序；也覆盖边线的有限灯数变体；临时全局裁切不用于可见场景绘制。
- 有限变体预热增加启动编译与程序缓存成本，换取运行时移除零亮度聚光灯计算且首次交互无需补链接。不能据灯数下降推断 FPS 或真实 GPU 帧耗时收益。
- Island 稳定 Basic 表面不执行 PBR 光照，不把首页收益套用于该状态。

## 验证

- `home-spotlight-pool.spec.ts` 独立 WebGL 对照：原 5 个常驻槽位与灯池 0/1/2 有效槽位的 Standard 表面实际像素读回，RGBA 最大通道差值要求 ≤ 2；同时检查真实 uniform 序列长度和强度为零的可见灯数量。
- 首页集成检查：聚焦 flanerie，快速切换 archive、pokeyard、宠物，再返回总览；实际观察到 0/1/2 灯，无可见零强度灯，交互前后程序数量不增加。
- 保留倒影提亮与正确透明顺序：总览缓存、聚焦合批直绘；明暗主题与桌面/移动端继续使用原 1% 像素差异阈值。
- 原始测量及源码指纹见 [证据 JSON](./home-spotlight-pool-2026-10-24.evidence.json)。

## 同环境工作量与预热采样

Chromium / SwiftShader，1440×900，DPR=1，复用 localhost:3000。统计主模型实际 Physical 程序中的 `spotLights` uniform 序列，不只检查对象数量。

| 状态 | 可见聚光灯：前 → 后 | 可见零亮度灯：前 → 后 | 主表面聚光灯槽位：前 → 后 | 完整绘制调用：前 → 后 |
| --- | ---: | ---: | ---: | ---: |
| 总览 | 5 → 0 | 5 → 0 | 5 → 0 | 36 → 36 |
| flanerie 聚焦 | 5 → 1 | 4 → 0 | 5 → 1 | 25 → 25 |

- 正常总览缓存路径仍为 10 次调用。A5 减少片元光照工作，没有声称减少绘制次数。
- 两轮软件渲染采样的预热耗时：修改前约 0.75 / 0.85 秒，修改后约 1.12 / 5.87 秒。波动明显，预热成本增加，不能据单个样本宣称启动更快，也不能视为硬件启动时间承诺。
- 程序数：基线总览 55、首次聚焦 56；最终版本总览 95、首次聚焦仍 95。增加有限变体的初始化成本，交互时复用。

## 最终检查结果

- 桌面/移动端共 14 个相关用例通过，2 个既有桌面限定用例跳过，覆盖灯池、完整首页像素、缓存、扫描及首次聚焦。
- 预热期间离场用例曾在并发 GPU 诊断下超时；隔离重测通过（3.3 秒），最终无未解决失败。
- 新增完整首页同姿态对照：依次使用 0 个有效灯、重新挂入 5 盏零亮度控制灯、再次移除；桌面独立探针最大 RGBA 差值为 0，桌面/移动正式用例均满足最大差值 ≤ 2。保留主视觉、光幕和提亮后的倒影。
- Vite 构建、修改文件 ESLint、差异检查通过。全量类型检查仍有 `WorkCard/index.vue:102` 和 `Craft/CraftContent.vue:91` 两处既有错误，本轮未新增。

# 模型延迟跟随性能优化

## 实现

- 稳定构图下，相同坐标且命中同一元素的指针采样直接返回，省去重复射线拾取、交互状态同步及渲染唤醒。入场、运镜、返回、边界失效和宠物聚焦继续执行完整逻辑。
- 输入缓动层收敛后直接固定目标，跳过后续指数插值；头部姿态独立收敛，不受其他模型动画是否仍在运动影响。
- 两级均收敛后才允许停止头部跟随渲染，避免快速反向移动时姿态恰好经过目标而提前停绘。
- 全身预览的身体角度收敛后直接固定终点，跳过重复阻尼计算。
- 保留两级缓动参数、转角范围、30Hz 输入采样和既有渲染上限。

## 测量

复用现有开发服务，使用 Chromium。先发送一次画布事件同步命中状态，等待渲染计数连续 300ms 不变，再连续发送 1000 次相同坐标的画布 `pointermove`，观察随后 250ms 的渲染计数变化。

| 指标 | 关闭事件去重的对照 | 启用优化 |
| --- | ---: | ---: |
| 额外渲染次数 | 4 | 0 |

计数来自 `renderer.info.render.frame`，表示渲染调用次数，包含内部渲染通道，不是显示帧率。对照仅在测试响应中关闭去重条件，其余代码和输入相同。这项结果不代表正常连续移动时的帧率提升。

## 验证

- 桌面模型两级延迟、单调收敛和无过冲。
- 重复画布输入不唤醒已静止场景。
- 全身预览的身体跟随和返回。
- 桌面与移动端的静态环境缓存复用、静止停绘、主题及尺寸变化后的缓存失效。
- 桌面与移动端的模块聚焦及返回后恢复跟随。
- 修改文件 ESLint 与 `git diff --check`。

- 日期：2026-10-12。
- 范围：路卡利欧、新叶喵、方尖碑、底座、碑文、挤出文字、反射环境与倒影。
- 方法：复用 `http://localhost:3000`，拦截真实 WebGL 调用；基线使用修改前的场景模块与环境资产，不重置工作区。

- 下载合计包含新增 3D 字形及各资源元数据，不包含页面 JavaScript、字体和图片；`sprigatito-sleep.bin.gz` 是唯一减面模型，实体和线框共用；原始构建输入位于 `scripts/assets/`。
- 绘制调用与上传数据在 Chromium 原生 Metal 后端、1280×800 桌面视口和 Pixel 7 模拟视口测量。测量脚本记录 `clear`、`drawElements`、`drawArrays` 与 `bufferData`；上传量是初始化累计量，不是总显存。交互期间的顶点、三角面数量不变。
- CPU 时间受并发浏览器、字体加载和 GPU 后端影响，不将单次耗时差异解释为稳定百分比收益。算法测试验证多姿态、旋转、非均匀缩放下的拾取结果与 Three.js 一致，姿态不变时重复拾取不再计算顶点变形。
- 环境采样由 256px 降至 128px，保留 HalfFloat HDR；已有桌面和移动截图检查。主画布分辨率、路卡拓扑、新叶喵减面误差及动作约束保持既有配置。

## 维护与回归

- `yarn optimize:model-assets`：读取已减面的新叶喵模型，重新压缩并生成文字网格和环境，更新内容版本；不会重复减面。
- `yarn build:sprigatito-model`：重新采样源姿势，并直接输出唯一的减面模型文件。
- `yarn build:lucario-model`：重新生成路卡、环境、文字和内容版本。
- `tests/model-optimization.spec.ts`：验证紧凑顶点、二进制布局、拾取结果、运行时依赖、绘制调用和上传预算。
- 既有回归覆盖聚焦/回程、画布尺寸、隐藏暂停、着色器与纹理复用、离场几何及加载失败重试。

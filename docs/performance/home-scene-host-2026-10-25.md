# B6：持久场景宿主与按状态加载

## 生命周期与资源边界

`templeSceneHost.ts` 在路由层和首页间提供单所有者资源转移，缓存 WebGL 场景而让页面组件照常卸载。

| 状态 | 行为 |
| --- | --- |
| 首次进入或缓存不兼容 | 原有模型加载、着色器准备与首次入场 |
| 首页及模块 URL 间切换 | 沿用现有场景内选择流程 |
| 离开首页 | 就绪场景暂停绘制、指针订阅、全局输入、尺寸观察与补间 |
| 短时间返回 | 绑定新 stage、按钮和回调，恢复入口选择、主题及原有简易淡入 |
| 闲置到期或预算超限 | 释放材质、纹理、缓冲、程序与 WebGL 上下文 |
| 未完成准备、关键回正中或上下文失效或曾发生丢失 | 释放并在下次进入时重新创建 |

- 最多保留 **一个闲置场景**，默认 **90 秒**到期。
- 驻留资源预算为 **256 MiB 保守估算值**，包含画布/多重采样与缓存缓冲、几何缓冲及纹理。此值不是真实显存读取，也不是硬件 VRAM 硬上限。
- `take` 将所有权交给页面并取消回收计时，旧计时器不能销毁已借出的场景；重复清理安全。
- 过期检查同时发生在计时器和获取资源时，避免后台计时器节流导致过期资源继续复用。
- 布局、主模型、运行特性模式、诊断开关、场景构建函数或当前宠物不兼容时释放缓存。`pagehide` 与宿主模块 HMR 清理也会释放闲置资源。

驻留时 canvas 被移动到轻量的离线容器，旧页面回调、按钮、标题及 DOM 补间引用被清除。避免通过 DOM 的 Vue 回指关系保留旧页面、页脚、弹窗和内容组件。只保留一份纯 3D 场景，返回时重新建立页面绑定。

## 按状态准备资源

- 路由确认进入首页时，存在驻留场景便跳过重复模型预取；实际获取时仍校验兼容性和有效期。
- 冷启动按当前宠物选择加载器，避免先预取默认宠物再加载当前宠物。
- 非新叶喵模型只在宠物聚焦需要构图基准时加载新叶喵参考缓冲；初始入口就是宠物聚焦时，在准备期间加载。
- 可选参考加载具有意图版本校验与光标加载反馈，切换入口、离页、销毁会取消旧意图的应用；失败后可重试，现有场景继续可用。
- 模块内容沿用原有选择时预取、运镜完成后挂载的流程。
- 切换宠物时，从资源持有集合移除已释放的旧几何；预热结束后清空任务闭包数组，保留必要材质以维持已编译程序。

## 恢复构图与交互

返回淡入与首次高机位运镜使用独立状态。尺寸更新只在首次运镜阶段应用入场相机，简易淡入始终保持恢复后的目标构图。历史返回仍恢复模块选择、展开状态和内容滚动；暂停的背景场景继续支持原有菜单交互。

旧回归测试曾要求配色工具页头可见，但该路由已有 `meta.noMenu = true`。测试改为验证页头隐藏，离场几何与光标状态断言保留。

## 实测与验证

复用现有 `localhost:3000`。探针只统计首页模型 canvas，排除独立粒子背景。

| 指标 | 首次就绪 | 离页暂停 | 返回 |
| --- | ---: | ---: | ---: |
| WebGL 上下文累计创建 | 1 | 1 | 1 |
| 程序累计创建 | 80 | 80 | 80 |
| 几何缓冲累计创建 | 86 | 86 | 86 |

桌面和移动端均确认 canvas 身份不变。离页后键盘、鼠标操作没有新增模型绘制、程序或缓冲创建。

固定正常模式与减少动效，总览首次就绪和历史返回后的完整 1280×720 模型画布对比：**0 / 921600 像素变化**。这不代表所有动画中间帧均已做逐像素比较。

验证范围：

- 宿主时限、预算、替换、不兼容、上下文失效、所有权转移与 pagehide。
- 真实 GPU 资源清理与桌面/移动布局不兼容后的重建。
- 当前宠物加载和参考缓冲延迟请求。
- 诊断关闭时的生产行为。
- 详情返回的选择、展开与滚动恢复，宠物切换、准备中离页取消、主模型及宠物离场几何（偏移不超过 1px）。

90 秒到期使用缩短时限的策略测试覆盖；真实 GPU 释放使用显式清理路径验证。内存预算为估算，未进行物理设备显存测量。全量类型检查仍有原有 `WorkCard/index.vue:102`、`Craft/CraftContent.vue:91` 两处 VueUse 类型错误。

主回归 **20 通过、4 按设备跳过、0 失败**；资源回收复核 3 通过、1 跳过；构建函数兼容性复核 3 通过。定向 ESLint 与 Vite 构建通过。

最终检查结果与采样见同目录 `.evidence.json`。

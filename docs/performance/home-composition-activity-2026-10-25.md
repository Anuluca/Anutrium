# 首页合成区域与动画状态优化（C1–C3）

## 范围

- 本轮开始已执行 `git add -A`，将当时全部修改加入暂存区；后续 C1–C3 修改独立留在工作区。
- 保留首页初始星空的 **40 FPS 配置与原调度函数**。审计报告的 12 FPS 是旧基线，本次不采用。
- 不启用 B5 自适应质量，也不新增常驻的全局 RAF（requestAnimationFrame）。

## 实现

| 项目 | 修改 | 行为边界 |
|---|---|---|
| C1 | Island 连线 SVG 从全视口改为端点包络；同步 CSS 原点与 viewBox，使用绘制隔离（paint containment） | 保留世界坐标、线宽、端点图案、卡片遮挡与独立语义按钮；保留封面滤镜和光标差值混合 |
| C1 | 包络预留 32px 运动余量，仅在越界或布局重测时更新尺寸 | 普通模型帧只更新坐标；无额外布局读取、Vue 更新或 RAF |
| C2 | `useMotionActivity` 共享可见性与减少动态效果订阅 | 粒子、页脚、内容装饰仍按自己的生命周期调度，最后消费者销毁后清理共享订阅 |
| C2 | 首页背景共用导航遮挡状态；隐藏的沉浸页脚及尺寸过渡中的 marquee 暂停 | 可见页脚继续滚动；沉浸模式星空继续运动；About 关闭过渡完成后才恢复背景 |
| C2 | 移动端全屏相册遮住模型时暂停三维场景，收起恢复 | 桌面相册仍显示模型，不暂停；不更改初始星空或模型像素预算 |
| C3 | 侧栏可见、遮罩方向、移动端相册展开改用页面已知 class | 遮罩方向保留到离场结束，避免关闭时渐变突然反转 |
| C3 | 首页布局与沉浸基础样式复用现有 shell / shell-leaving 类 | 不提前清理离场 shell；保留其他范围内仍有用途的 `:has()` |

| Pixel 7 | 31.470% | PNG 完全一致 |

- 模型端点在余量内连续移动 20 帧，SVG 尺寸不变；端点越界后自动扩展，保持描边完整。
- 粒子停用、页面隐藏、减少动态效果及卸载后均无持续重绘。
- 与暂存基线比较，粒子 `animate` / `syncAnimation` 源码完全一致，SHA-256：`cde4f0bfe838401a7b2c58247db3f944b47fe4a2ae7835d77d4222ac5c912468`。

上述面积是受控场景的 DOM 绘制范围，不等于 GPU 时间或整页帧率提升。真实集显、Mac 浏览器、iPhone Safari 的 GPU 合成收益尚需实机轨迹验证。

最终去重回归结果：**26 项通过、2 项设备适用性跳过**，包括桌面/移动端：

- 实际模型锚点、卡片命中及焦点重绑；最终实测父组件与布局组件更新均为 0。
- 首页沉浸淡出/恢复、初始星空预算、About 关闭等待、页脚状态与宽度过渡。
- 花花与主模型路由离场几何（偏移不超过 1px）、相册展开布局和淡入淡出。
- 移动端全屏相册展开后，模型绘制计数在 350ms 采样内不增加；收起后重新增加。

首轮真实场景桌面锚点采样曾观察到一次布局组件更新，触发源未被捕获；未放宽零更新断言。补充触发记录后复测桌面/移动端均为 0；固定源连续帧测试也保持 0 更新。原始与最终结果保存在同名 evidence.json 中。

Vite 构建（12.72s）、定向 ESLint、滚动安全静态检查与 `git diff --check` 通过。全量类型检查仍有既存的 `WorkCard/index.vue:102`、`Craft/CraftContent.vue:91` 两处 VueUse 元素类型错误，本轮没有新增类型错误。

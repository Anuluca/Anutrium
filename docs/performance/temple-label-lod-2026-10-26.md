# 立体标签细节层次（Level of Detail，LOD）与平面替代

## 实现范围

为首页模型的 ISLAND 字样增加自动 LOD 与固定平面模式。默认从原高档开始；其它档位在实际需要时加载。只改变标签几何，星空帧率、画布像素预算和其它效果等级保持原状。

| 档位 | 面数 | 顶点 | 几何数据 | gzip 资源 |
|---|---:|---:|---:|---:|
| high | 1,984 | 3,688 | 115,168 B | 33,743 B |
| low | 392 | 612 | 19,488 B | 4,475 B |
| flat | 242 | 250 | 8,452 B | 2,903 B |

平面版从原高档二进制提取正面三角形，坐标、字孔、六个字符 ID、前表面深度逐项一致。它是零厚度的矢量网格，没有新增字体或纹理。相对高档减少约 87.8% 的面数、92.7% 的几何数据。元数据保留高档的半高和深度作为布局参考；实际平面顶点的 Z 跨度为 0。

逐字推出、扫描线、主题染色、透明队列与深度测试均复用原材质。任一时刻只绘制一个标签 Mesh，切档只更换 geometry，材质和渲染顺序不变。

## 默认 LOD 策略

尺寸以标签前表面在视口中的 CSS 像素高度计算，不使用 DPR 或实测 FPS。

- 显现、运镜、返回等过渡期间恢复高档；此时也跳过不必要的尺寸投影计算。
- 稳态下，高档小于 28px 才降级；低档达到 36px 才升为高档。
- 小于等于 12px 且接近正视（法线与相机方向点积至少 0.995）才进入平面档。
- 已进入平面档时，保持至高度达到 16px，或正视点积小于 0.985。
- 点积小于 0.96 时直接选择高档，保留斜视下的厚度和倒角。
- 平面档退出而低档尚未下载时，先恢复已缓存高档；不会因网络等待而继续显示不合适的平面字形。
- 隐藏标签不触发额外档位请求。

阈值带滞回，避免轻微尺寸变化导致来回切换。切换边界可通过固定档位对比确认，不以这些阈值推断真实硬件帧率收益。

## 加载、缓存与销毁

- 默认入口只准备高档，保持原主视觉和预热路径。低档、平面档首次需要时下载，后续复用各自 Promise。
- 网络回调只保存 CPU 数据并请求原有按需帧；下一有效帧重新判断档位，不提交过期请求，也不在暂停/驻留场景后台创建 GPU 几何。
- 单场景最多缓存三份标签几何，原始索引与顶点数据合计 143,108 B；任一帧只有一份参与绘制。
- 标签继续复用同一着色器；没有新增常驻 RAF、观察器或质量采样定时器。
- 下载失败保留可用几何，重复失败请求有 30 秒冷却；重试由后续有效交互帧触发。
- 场景销毁后异步回调不再触发绘制或创建几何；全部已注册几何由场景统一释放。持久宿主正常暂停、恢复、超时释放。

## 配置

```dotenv
# 默认；按标签投影尺寸和视角切换
VITE_HOME_LABEL_QUALITY=lod

# 固定对比：high / low / flat
# VITE_HOME_LABEL_QUALITY=flat
```

环境配置在 Vite 启动/构建时生效。固定档位保留原有行为，不自动升级或降级。几何构建继续使用：

```sh
yarn build:temple-labels
```

该命令生成三档资源和内容版本，不启动开发服务。

## 验证

- 正面三角形、字符 ID、平面零厚度和布局参考数据逐项对比通过。
- 策略覆盖尺寸/视角滞回、隐藏不请求、过渡升档、过期请求、下载失败安全回退、有限缓存与卸载后异步回调。
- 真实 WebGL 高→低→平面→高切换验证：同一材质、同一高档几何复用，仅新增两份几何，新增着色器程序数为 0。
- 路由离开后按原 Canvas 身份继续拦截绘制，驻留采样期零绘制；返回后 Canvas、材质、几何数量保持一致，三档可继续复用。
- 已查看桌面平面/LOD 截图；聚焦标签的位置、逐字效果与扫描线保留。

# B3：固定尺寸光标图层

## 改动

- `.cursor-shape` 固定为 36px 设计尺寸，保持居中；沿用项目 rem 转换与响应式缩放。
- `.cursor-size` 以 `transform` 在 2/3 和 1 之间过渡，采用 360ms 缓动。圆形与三角形使用独立固定图层，通过 `opacity` 切换；三角形裁剪不参与插值。
- 外层继续负责跟随、按压和加载脉冲，三角形内部图层负责悬停旋转，圆形层负责移动与滚动变形，避免 transform 相互覆盖。
- 保留白色差值混合、主题光晕、24px 圆形、36px 三角形、移动 1.2 倍、按压 1.3 倍、2s 旋转、滚动回弹、加载优先级、隐藏暂停、闲置停 RAF、触屏禁用。
- 更新已过期的路由加载测试：首页菜单现为模型聚焦入口，测试改用旅程详情到配色工具的真实路由切换。

## 测量

复用 localhost:3000，使用隔离 Vue/Pinia 光标夹具，避免首页 WebGL 与其他页面动画干扰。Chromium DevTools Protocol 的 `Performance.LayoutCount` 统计 1100ms 单次悬停窗口。

| 指标 | 改造前 | 改造后 |
| --- | ---: | ---: |
| 悬停窗口布局次数 | 155 | 1 |
| 过渡期间布局宽高 | 24 → 36px | 固定 36px |
| 连续形状动画属性 | width / height / margin / background-color / border-radius | transform / opacity |

改造后保留一次状态切换计算，不再逐帧改变布局。布局次数受采样帧数影响，此处不推导整站 FPS 或 GPU 收益。

截图在相同背景、动画相位与 120×120 裁剪区比较：普通圆形与移动圆形逐像素相同；旋转、滚动、按压和加载的平均 RGB 通道差异均小于 0.26/255。固定图层变换存在抗锯齿差异，不能称全部状态逐像素一致。形状切换改为图层缩放与淡入淡出，取消旧的圆角插值；保留尺寸、时长、旋转与交互反馈。

## 验证

Playwright：16 通过、14 按设备跳过、0 失败。

- `cursor-performance.spec.ts`：已有跟随、停绘、闲置、滚动、隐藏恢复、共享指针采样及触屏行为。
- `cursor-shape-layers.spec.ts`：固定布局、悬停中断与反转、布局次数、按压、悬停期间加载覆盖。
- `cursor-loading.spec.ts`：按压、主题反色及真实路由加载周期。
- 定向 ESLint 与 Vite 构建。
- 全量类型检查仍受已有 `WorkCard/index.vue:102`、`Craft/CraftContent.vue:91` 两处 VueUse 参数类型错误阻塞。

原始数值见同目录 `.evidence.json`。差值混合与光晕仍有合成成本，未做真实硬件 GPU 耗时测量。

## 后续修正：三角形切换衔接

- 移除悬停时对整个尺寸层的瞬时三角裁剪，避免圆形在淡出前先被切角。
- 圆形与三角形统一 240ms 淡入淡出，尺寸缓动缩短至 360ms，避免原先 0.2s / 1s 时长不一致。
- 旋转移至三角形内部，持续复用同一 CSS 动画。离开时暂停并保留相位，重新进入时继续；圆形与滚动椭圆不继承旋转。
- 新增交叉淡化、无父层裁剪、旋转暂停与相位续播回归断言；16 通过、14 按设备跳过，定向 ESLint 与构建通过。
- 后续隔离测量：500ms 悬停窗口共 2 次 Layout（状态切换），没有恢复逐帧布局。上表与截图差异数据为首轮 B3 的历史测量。

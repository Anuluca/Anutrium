## 相机与切换

- `createDollyCameraMotion` 接收可选的投影更新回调，默认行为仍为立即更新，保持独立调用兼容。
- 场景将缩放、视角、画面偏移的投影更新标记合并。在每帧时间轴更新完成后统一重建矩阵，再更新模型投影和锚点。
- resize 仍立即应用完整视口投影，保证命中、构图和路由离场几何一致。

## 布局与交互

- 通过稳定的 Map 节点引用缓存视觉卡片和标题；以缓存引用订阅 ResizeObserver，移除测量过程中的 DOM 查询与祖先查找。
- resize、字体就绪、语言和移动布局变化统一合并到一个待执行 RAF，卸载时取消。
- 同一次测量先读完全部尺寸，再批量写标题缩放和连线原点，避免标题之间读写交错；相同缩放值不重复写入。
- 预计算双语标签、占位状态、线上 R2 桌面/移动缩略图 URL，视觉层与点击层复用同一组数据。
- 缓存连线基础数据和 ID 索引，hover 时以线性顺序调整替代排序；稳定 ref 回调避免重复节点绑定。
- 保持 CSS 网格、视觉层/点击层分层、键盘操作及点击闪烁行为。

# 首页投影计算与标签质量分级（C6、C7）

2026-10-26 更新：标签已扩展为自动 LOD 与平面档，当前默认行为见 [LOD 实现记录](./temple-label-lod-2026-10-26.md)。以下保留固定两档实现的历史验证数据。

## C6：小对象与重复数学计算

已有优化保留：五个 Island 锚点复用固定坐标对象；连线列表仅在内容/悬停状态改变时更新；诊断格式化受显式开关控制。没有新增通用对象池。

本轮修改：

- 相机的视图、投影矩阵每次投影批次合并一次，再按对象合并世界矩阵。每个点由三次向量矩阵变换改为一次；四柱 36 个轮廓点由 108 次降至 36 次，五个模型锚点由 15 次降至 5 次。矩阵合并本身有额外固定开销，不能据此等比例推断 CPU 时间。
- 两个辫子锚点共用一次低头四元数计算，保持原先的低头、转头顺序。
- 头部欧拉角不变时，不重复计算四元数或写入头部旋转 uniform。
- 复用指针命中采样对象与轮廓排序比较器，直接拼接轮廓字符串，去掉相机移动时的临时采样对象、比较器闭包与 `map()` 中间数组。
- 不改变绘制唤醒、闲置停绘、扫描、运镜与星空的调度逻辑。

数值回归覆盖 120 种相机/对象变换、1,080 个点，包含横竖屏纵横比、旋转和非均匀缩放；与原 `applyMatrix4(world).project(camera)` 比较，误差要求小于 `1e-10`，输出向量身份保持不变。

### 配置和构建

```dotenv
# 默认；保留现有画面
VITE_HOME_LABEL_QUALITY=high

# 需要固定较低标签几何成本的部署可改为 low
# VITE_HOME_LABEL_QUALITY=low
```

Vite 环境配置在启动/构建时生效。只加载所选档位，两个档位的下载 Promise 独立缓存；路由预加载与场景创建沿用同一个配置。没有设备猜测、运行中自动切档或 B5 自适应像素预算。

```sh
yarn build:temple-labels
```

此命令离线生成两档资源，并更新资源内容版本；完整路卡模型构建也会生成两档。不会启动开发服务。

## 验证边界

- 两档资源均验证有限坐标、合法索引、六个字母 ID、同尺寸、独立缓存和无重复下载。
- 桌面和移动端实测两档均只请求所选资源；标签显示、五条锚点连线、聚焦返回和初始 40 FPS 星空配置通过检查。
- 已查看桌面两档及移动端低档截图，低档保持 ISLAND 字样、扫描线及原位置；曲面与倒角细节减少属于低档的预期差异。
- 资源大小与面数是实际产物数据，不代表整页帧率提升。标签原有规模较小，真实硬件 CPU/GPU 时间仍需实机采样。

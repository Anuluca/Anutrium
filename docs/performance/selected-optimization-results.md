## 2. 实测结果

### 2.1 3D 矩阵调用

同一桌面视口 1440×900、Apple M4 Metal 后端；本地提供生成字体，屏蔽 Typekit 与开发 WebSocket。插桩只修改浏览器收到的响应。

| 每个实际绘制帧的平均值 | 聚焦：优化前 → 后 | 失焦：优化前 → 后 |
| --- | ---: | ---: |
| 渲染器内部世界矩阵函数调用 | 141 → **0** | 141 → **0** |
| 渲染器内部局部矩阵更新 | 44 → **0** | 44 → **0** |
| 包括应用显式更新的世界矩阵调用总量 | 168.98 → **72.47** | 170.00 → **73.65** |
| 包括应用显式更新的局部矩阵更新总量 | 51.72 → **5.44** | 52.00 → **5.48** |

- 稳定静止 1.5s，前后均为 **0 次场景绘制**。
- 20 组嵌套位移、旋转、非均匀缩放和非默认根变换，与标准 Three.js 更新结果最大矩阵误差为 **0**；无变化时不传播世界矩阵。
- 部分绘制帧只改变材质/相机，没有场景对象变换，因此不必每个绘制帧遍历全部场景。动态场景仍在需要时统一传播。
- 聚焦前后采样分别 170/177 帧，失焦均 178 帧；绘制调用基本保持既有规模。这里统计的是函数调用，**不等于矩阵乘法数或系统 CPU 使用率**。

### 2.2 冷进入生产路由

最新 SSG 构建通过请求拦截映射到已有本地服务，每页独立浏览器上下文，禁用 Service Worker，等待入口完成。统计实际请求文件的未压缩体积；gzip 是逐文件估算，非线上 Brotli 传输体积。

| 路由 | JS：之前 → 当前 | gzip 估算：之前 → 当前 | CSS：之前 → 当前 | 运行时异常 |
| --- | ---: | ---: | ---: | ---: |
| `/` | 1,143,895 → **1,052,019 B** | 344,133 → **313,605 B** | 290,117 → **241,999 B** | 0 |
| `/archive` | 1,221,658 → **1,220,633 B** | 376,730 → **378,391 B** | 394,319 → **395,312 B** | 0 |
| `/craft` | 1,050,814 → **995,639 B** | 311,462 → **294,691 B** | 345,890 → **316,439 B** | 0 |

- 首页已请求 JS 体积下降约 **8.0%**，CSS 下降约 **16.6%**；这不是加载耗时或 CPU 使用率的下降比例。
- 首页 HTML 静态依赖图：JS 从 1,004,310 降至 **910,886 B**，gzip 估算从 294,375 降至 **263,248 B**。
- 首页不再提前请求旧页 Swiper 和路由级 Element Plus 弹窗/表单组件。Archive、Craft 的实际内容仍会按需求加载组件，不能要求这些页面完全排除 UI 库。
- 字体实际请求 URL 数首页/Archive/Craft 分别为 28/33/31；字体子集重排属于未选择的 #2，本轮没有更改字体内容或覆盖范围。
- 生产环境 CSS 规则跟踪只返回跟踪到的规则，不能据“未执行规则 0”判断没有可拆分 CSS。
- 本轮没有可靠的真机 CPU 百分比、生产真实用户 LCP/INP/CLS 或 Typekit 独立收益，不提供推算分数。

- `yarn check:overlay-scroll`：通过。
- `yarn test:overlay-scroll --config=.tmp/playwright-selected-perf.config.ts`：**8 项通过**，覆盖桌面/移动图片预览、视频弹窗、确认框与社交弹窗；滚动、锚点及 body 宽度偏移满足 ≤1px。
- 桌面/移动主题和悬停、光色/倒影、方尖碑聚焦失焦、新叶喵交互定向复测：**6 项通过**。
- 贡献图可见性、粒子暂停、矩阵、About 并行预取、Footer 几何与位图缓存新增回归：前六项在两种项目下 **10 项通过、2 项按设备条件跳过**；最后增加的材质回归在上项复测中通过。

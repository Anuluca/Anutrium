## A4：四柱与倒影合批

- 新增 `scene/pillarBatches.ts`：八组正面实例批次（碑身、底座、光晕、光池各一组，晶体与内芯各前后两排），六组镜像批次（碑身、晶体、底座各前后两排）。主底座保持独立。
- 按几何、材质种类、贴图、顶点色、单双面、混合、深度、裁切和绘制顺序分组；碑文独立画布和专属染色钩子继续独立绘制。
- 每组共享一个渲染材质，通过 uniform 提交同批柱子的矩阵、颜色、自发光、粗糙度、金属度、环境强度和透明度；实例矩阵缓冲初始化后不随动画上传。
- 原 Mesh 保留射线拾取身份；原 Material 作为既有动画控制状态保留，并关闭其渲染可见性。不是删除所有重复 JavaScript 材质对象：场景中材质对象总数 84 → 95，首页可见对象所引用的有效材质数 53 → 40。
- 永久透明对象按前后排拆成两个批次，保留与角色倒影及晶体内芯的交错排序；光晕/光池可保持四柱一起绘制。uniform 变换另行更新真实排序中心，避免默认实例包围球停在原点。
- 升降、悬停、主题与渐隐走共享数据；隐藏实例在顶点/片元阶段剔除，缓存深度使用相同实例矩阵，避免原点残留遮挡。
- 保留上一轮倒影参数：角色使用 Standard 明暗层次，底座倒影不透明度主底座 0.51、四柱底座 0.58。

## A6：扫描表面合并与重心坐标评估

- 黑色填充、重心坐标线框（Barycentric Wireframe）和扫描亮边/光晕合为一个预乘透明合成表面。扫描从四个模型表面降为三个：Physical 主表面、深度预通道、合成表面。
- 保留深度预通道，遮住背面线框；合成表面的黑色内部 alpha=0.55，边缘逐渐过渡到实色。稳定 Island 仍为三次调用，包含标签。
- 主表面的物理光照、头部变形、倒影和拾取继续使用原索引几何；仅合成表面展开为 4,581 顶点并增加归一化 Uint8 重心坐标。移除该副本不使用的法线及形变法线。
- 合成副本属性合计 105,363 字节；替代原线框约 18,324 字节索引后，估算净增 87,039 字节（约 85 KiB）。主表面原几何仍共享，不重复替换。
- 线宽由屏幕导数 `fwidth` 控制；稳定端点跳过扫描噪声和发光。原外扩 0.006 的独立光晕壳改为表面亮边，轮廓外侧辉光范围略收敛。
- 保留独立 Physical 主表面：避免稳定线框仍承担整套 PBR；目前未将所有表面强行合为单个昂贵材质。
- 取舍：减少扫描提交和重复线段绘制，增加非索引顶点与三角形片元工作。软件渲染计数不能证明硬件 GPU 更快，后续硬件采样应同时比较扫描与稳定态。

## A7：队列与双面审查

| 对象 | 最终策略 |
| --- | --- |
| 主模型 Physical | 稳定不透明队列；保留双面和既有单遍，避免裁切开口改变 |
| 原本不透明的建筑/宠物 | 稳定时不透明；仅渐隐或实际 opacity<1 时切透明队列 |
| 半透明宠物 | 保留原前后两遍，避免渐隐外观变化 |
| 晶体与角色倒影 | 保留透明、双面及既有单遍策略 |
| 加法光束 | 双面单遍，减少正反面重复提交 |
| 扫描合成表面 | 单面、透明、预乘 alpha、不写深度；前置深度预通道维持遮挡 |
| 完全隐藏的底座/倒影 | 直接关闭可见性，避免提交最终被 alphaTest 丢弃的表面 |

加载时预热不透明、透明及实际主帧缓冲变体；跳过仅作控制状态的隐藏原材质。同次最终测量的 `linkProgram` 检查：首页就绪 56 次，首次进入 Island 后仍为 56 次。程序总量较本轮前有所增加，是实例材质/队列变体的成本，并非声称所有资源指标下降。

## 后续视觉调整：倒影提亮

- 降低地面覆盖 alpha：近处 0.97 → 0.92、远处 0.58 → 0.46，让下层镜像更清楚。
- 主模型镜像 opacity：0.42 → 0.52；建筑：0.46 → 0.52；宠物：桌面 0.25 → 0.34、移动 0.125 → 0.18。
- 底座镜像覆盖倍率 1.5 → 1.8，上限 0.58 → 0.68：主底座实际 0.612、四柱底座 0.68。
- 保留 Standard 材质、切面明暗、现有粗糙度与自发光限制；不额外叠加白色高光。上方性能表和证据指纹仍对应 A4/A6/A7 完成时的测量快照。
- 加强像素验证后发现：柱子聚焦构图中的光幕、角色及倒影存在交错透明层，单张静态环境缓存会改变叠加顺序。缓存现仅用于首页稳定总览；聚焦继续实例合批直绘，静止停绘规则不变。测试显式检查该路径，并维持原 1% 像素差异阈值。
- 晶体边线显式在晶体/内芯之后叠加，避免合批对象 ID 改变同深度顺序。提亮后的桌面/移动明暗主题像素回归 2 项通过；桌面首次聚焦预热与静止停绘回归通过。

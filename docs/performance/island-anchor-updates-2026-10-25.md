# B2：高频模型锚点绕开 Vue 渲染

日期：2026-10-25。对应 [3D 性能审计 B2](../research/3d-performance-audit-2026-10-24.md)，接续 B1 后的当前场景。

## 实现

- `TemplePage.vue` 使用非响应式通道保存最新投影，将坐标同步传给已挂载布局的 `updateAnchors`；组件重挂载时立即补发最新坐标。
- `IslandFocusLayout.vue` 保留 Vue 对卡片、语言、悬停、键盘焦点及点击闪烁的管理。连线列表只依赖静态条目及悬停状态，不再依赖模型帧坐标。
- `scene/islandLinkOverlay.ts` 缓存五组 SVG 节点，只更新变化的 `x2`、`y2` 和端点 `transform`；不额外创建 RAF，不在高频路径查询 DOM 或读取布局。
- 保留原有整组提交语义：任一坐标相对上次提交累计移动达到 0.25px，提交五个点的当前投影；不能拿可变输入对象本身充当历史快照。
- 卡片侧起点由现有 ResizeObserver、语言、字体及布局变化重新测量，直接更新 SVG；初次挂载增加一次同步测量。
- 头部与镜头投影沿用原计算顺序。模型端复用投影函数、坐标容器及五个点，避免每帧创建六个坐标数据对象。
- SVG 节点使用稳定 key；悬停/键盘焦点仍由 Vue 排序，将当前高亮连线放到末尾。坐标属性由命令式更新独占，Vue 不再绑定这些属性。
- 卸载时清除节点引用；字体完成后的迟到测量和旧更新方法均停止写入。

受控夹具使用真实布局组件、相同坐标轨迹、相同字体和占位图数据。每次输入移动超过 0.25px，连续输入 40 组；基线使用修改前组件及响应式父组件，优化后使用实际公开更新方法。模型本体不参与这组渲染次数测量。

真实 Island 模型跟随测试中，两端父组件及布局组件的 beforeUpdate 均为 0，SVG 坐标确实持续变化；原模型坐标容器、五个点及五组 SVG 节点均保持同一对象身份。最终采样的最大坐标误差为桌面 0.245px、移动仿真 0.238px。

## 验证与边界

- 沿用已有 localhost:3000 服务，没有启动或停止开发服务。
- 隔离测试验证原地更新对象、累计 0.25px 阈值、无变化不写属性、无额外布局读取/DOM 查询，以及卸载后旧方法无副作用。
- 真实模型测试覆盖鼠标跟随、窗口缩放、语言切换、键盘焦点置顶、退出后重新聚焦；卡片侧起点误差要求小于 1px。
- 原 `island-modules.spec.ts` 两端通过：布局、五个模型锚点、悬停配色、语言、点击闪烁、导航及离场期间页面/路由容器偏移不超过 1px。
- 初次新增的重挂载测试通过裸路由跳转 `/` 请求退出；当前路由守卫不会据此退出模型聚焦。测试已改用页面实际使用的导航 store 请求，验证组件卸载与重挂载，本轮不修改路由行为。
- 共 8 项不同目标测试通过，包含桌面和 Pixel 7 仿真；不是实体手机性能测量。
- SVG 仍然重绘，3D 模型绘制工作不因本项减少。没有测量或宣称硬件 GPU 帧耗时、FPS 固定提升。
- Vite 构建通过（7.96 秒），修改文件 ESLint 与差异空白检查通过；全量类型检查仍有 `WorkCard/index.vue:102`、`Craft/CraftContent.vue:91` 两处既有 VueUse 引用类型错误，本轮文件无新增错误。

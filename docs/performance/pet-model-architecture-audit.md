# 宠物模型与切换架构审查

- 日期：2026-10-14（Asia/Shanghai）。
- 以下为架构清理完成时的测量快照；后续几何面块造型进一步改变了模型几何，当前面数与风格见 `docs/references/flora/pet-models.md` 的三模型面块章节。
- 范围：宠物身份与切换、两只宠物的模型加载、聚焦取景、头部变形与射线拾取、几何生命周期、扫描线算法、小黑离线构建；复核路卡共用环境及材质。
- 保留当前视觉参数：模型初始／最终朝向、大小、位置、环境旋转和双倍跟随幅度。原始模型、骨架、动画与 PNG／BNTX 素材保留。

## 2. 修改

| 路径 | 问题 | 实现 |
| --- | --- | --- |
| `scene/petFocusCamera.ts` | 原取景算法内嵌大场景，重建数千个 Vector3，并在二分距离时重复做矩阵变换。 | 拆出独立模块；仿射变换直接写连续数值缓冲；顶点预投到固定相机基底；二分时只调整俯仰及深度。 |
| 聚焦取景缓存 | 同一模型相同构图反复遍历顶点。 | 弱引用映射（WeakMap）按几何体缓存最近结果；视口、相机参数、缩放、朝向、位置与参考模型变化时失效。返回向量副本，防止调用方修改缓存。 |
| 尺寸诊断 | 鼠标跟随时重复扫描最终姿态的 1069／2136 个顶点，结果实际相同。 | 按几何体与组合投影矩阵缓存；矩阵未变只比较 16 个数值。缓存不改变实际渲染或变形。 |
| `templeScene.ts` | 每帧重新拼接实体、线框、深度与倒影网格列表。 | 初始化一次固定列表，逐帧变形及模型替换均复用。继续释放旧几何体，不新增常驻 GPU 模型副本。 |
| `smoothMightyenaEyes.ts` | 边界每走一步都复制、过滤剩余边集合，最坏平方复杂度。 | 用端点映射表（Map）查找下一条有向边；边界追踪从 O(E²) 降为 O(E)，保留开放／分叉检测。此收益属于离线构建。 |
| `prepareMightyenaGeometry.ts` | 四个姿态重复请求同一组原始文件。 | 缓存输入 Promise，四个姿态共用四次文件请求；失败清除对应缓存。 |
| `bakeSprigatitoRenderAssets.mjs` | 为每个属性、顶点构造临时数组再 flatMap 展开。 | 预分配最终 Float32Array 并直接填充；UV 在简化约束之后剔除。 |
| `build-flora-pets.mjs` | 在 `node -e` 中被导入时 `process.argv[1]` 为空，入口判断抛异常。 | 增加入口存在性判断，支持直接导入构建函数。 |
| 动画诊断测试 | 一帧一次的采样可能错过透明度为 0 的短边界。 | 在模型提交时发布真实透明度，测试额外观察该属性变更；未修改动画持续时间或 easing。 |

### 算法微基准测试（Microbenchmark）

- 本地 Vite、无页面 GPU 绘制的 Chromium headless；资源已下载。
- 每个场景执行 500 次不命中缓存的取景计算、1000 次缓存命中计算与投影诊断计算。
- 以下为批次平均值，反映算法局部成本；不能直接换算为整页帧率、真实设备交互延迟或核心网页指标（Core Web Vitals）。

| 模型／构图 | 原取景 ms | 新首次取景 ms | 缓存取景 ms | 原尺寸诊断 ms | 缓存尺寸诊断 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| sprigatito／桌面 | 0.1876 | 0.0520 | 0.0008 | 0.0166 | 0.0006 |
| mightyena／桌面 | 0.2870 | 0.0798 | 0.0003 | 0.0355 | 0.0001 |
| sprigatito／移动 | 0.1824 | 0.0540 | 0.0004 | 0.0192 | 0.0002 |
| mightyena／移动 | 0.2900 | 0.0740 | 0.0004 | 0.0319 | 0.0002 |

- 优化前后相机位置及目标位置最大误差低于 `4e-15`；尺寸投影误差低于 `3e-16`。
- 数据见 [pet-model-architecture-audit-data.json](./pet-model-architecture-audit-data.json)。未采集生产环境 Core Web Vitals；当前没有可直接调用的 DevTools trace MCP 工具。

## 4. 保留的实现与边界

- 未发现数据库查询或 N+1 查询路径。模型下载已并发并去重，保留现有 `cachedModelLoader`，不增加预下载未选宠物。
- 扫描线生成仅发生于组件初始化／编号变化，已有 computed 缓存；未引入无限增长的全局图案缓存。
- 宠物查找仅两项，未把所有小数组搜索机械替换成 Map。改动集中于确有重复遍历的取景、诊断与眼窝边界追踪。
- 保留按需渲染、共享指针限频与会话资源缓存；未引入新依赖或新开发服务。

# About 运行时性能排查（2026-10-18）

## 测量范围

- 复用 `http://localhost:3000`，检查独立 `/about` 与首页 About 聚焦层。
- 使用 Playwright 与 Chrome DevTools Protocol（CDP）采集 CPU Profile、渲染时间线、布局次数和资源请求。
- 主对照使用 Apple M4 / ANGLE Metal、1440 × 900、DPR 2。首次软件 WebGL 采样单独保存，不能与硬件加速样本比较帧率。
- 页面测试会阻断 Adobe 网络请求以隔离第三方波动；实际性能采样保留线上字体和图片请求。页面没有引入本地 R2 回退。

## 量化结果

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| Logo 每帧 WebGL 绘制批次 | 11 | 2（减少约 82%） |
| 250 次/秒模拟动画回调下，星空每秒绘制上限 | 随回调频率绘制 | 约 60 次 |
| 同一路径 120 次鼠标移动采样中的同步强制布局 | 18 | 3 |
| 离屏/后台扫描线与友情链接闪烁 | 继续动画 | 暂停，恢复可见时继续 |

布局数字来自 CDP 时间线中嵌套于 JavaScript 调用内的 Layout 事件，不等于页面所有布局，也不能换算成固定 FPS 提升。新增测试分别约束指针移动布局预算、GPU 绘制批次、后台暂停，以及高频回调下的粒子帧率上限。

## 尚存限制

- Adobe Typekit 是实际使用的阿里巴巴普惠体来源，冷加载存在 MB 级字体下载及动态 DOM 观察开销。保留现有字体，未用替换字体或私自复制 Adobe 托管字体规避这一成本。
- 首屏加载仍受字体 CDN 与网络影响。单次采样的最大内容绘制（Largest Contentful Paint，LCP）受字体到达时间影响，不能把两次冷加载的差值全部归因于本次修改。
- 本次没有采集真实用户交互到下一次绘制（Interaction to Next Paint，INP）数据，也不以开发服务器样本代替线上用户指标。

## About 聚焦层的背景休眠

- 首页场景、当前活动模块及详情容器统一放入 `temple-underlay`。打开 About 时渐隐 400ms，结束后通过 `v-show` 设置 `display: none`，退出布局、绘制和合成；保留组件实例、模型资源和模块滚动状态。
- 背景 3D 使用独立遮挡开关，优先于入场动画。打开时同步暂停帧循环和指针订阅；About 离场完成后才恢复并渐显背景。减少动态效果模式使用 10ms 过渡。
- About 关闭后的焦点恢复延后到背景恢复之后；快速重开时不响应旧的离场完成事件。
- 新增桌面与手机自动化用例：验证背景真正隐藏、隐藏期间 WebGL 绘制计数不变、关闭时序、模块和 Canvas 实例保留、滚动位置与背景几何恢复。
- 既有首页路由离场测试改为观察实际的固定定位几何锁定阶段，以匹配当前 `css: false` 的 JS 路由过渡，不再等待已不存在的 `route-leave-active`；偏移容差保持 1px。
- 本轮验证结果：背景休眠与首页离场几何共 4 项（桌面、手机）通过；弹窗滚动安全共 8 项通过；类型检查、修改文件的 ESLint、生产构建与 `git diff --check` 均通过。背景隐藏期间实际 WebGL 绘制计数保持不变。

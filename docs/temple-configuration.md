# 神殿配置入口

- `src/config/pageThemes.ts`：路由与模块共用的主题色。修改 `HOME` 会同步默认页面、雕像、网格、灯光、圣光、地面与倒影。
- `src/config/templeNavigation.ts`：柱子名称、可用性、位置、悬停主题色及 `zodiacSign` 星宿配置。四个模块均可聚焦；ISLAND 与 POKÉYARD 暂只显示标题。`POKÉYARD` 使用 `#F1C640`。
- `src/config/templeExperience.ts`：默认模型、加载适配器、尺寸、裁切和头部动作参数。

## 替换模型

`TempleModelDefinition.load()` 返回 `IslandModelAsset`，使用现有静态缓冲区格式（顶点、法线、索引、头部两组权重、支点、包围尺寸及环境贴图）。其他格式的资源在该适配器中转换，不需要改动场景布局或菜单。无头部动作的模型可提供零权重，并设置 `rig.enabled = false`；身体转动单独由 `rig.bodyYaw` 控制。

在 `templeExperience.model` 选择默认模型，或向 `createHomeTemple` 的第五个参数传入其他 `TempleExperience`。加载器应缓存下载结果；场景会创建独立 GPU 资源并在离场时释放，避免修改缓存顶点。

## 调整主题

默认主题读取 `pageThemeColors.HOME`。聚焦模块使用对应路由主题；退出恢复默认主题。「关于」打开期间恢复网站红色主题，关闭后恢复原模块主题。

聚焦时星盘切换为原有内容半屏布局，并沿最短路径旋转至模块星宿；默认大道使用居中布局。作品集为水瓶座、旅程为射手座、个人海湾为双鱼座，宝可后院沿用未指定路由时的狮子座，可通过 `zodiacSign` 调整。

场景实例提供 `setThemeColor(color)`，仅缓动颜色 uniform，不重新下载模型、不重新编译着色器、不创建后处理通道。材质保留原来的明暗层次、粗糙度与光照强度。

## 头部与悬停

`rig.pointerDamping` 控制鼠标跟随缓动（值越小延迟越明显），`rig.focusYawLimit` 限制聚焦转头角度。聚焦时从雕像和柱子的世界坐标计算朝向，退出恢复鼠标跟随，无需先回正。网格预览退出的低头归位仍单独保留。

方尖碑悬停复用每根柱子的材质颜色目标，碑身、底座与晶体同步着色，其余场景使用可恢复的亮度倍数；倒影仍复用原几何体和材质，不增加离屏通道。

## 聚焦内容展开

桌面端先淡出分类头部，再缓动面板实际宽度及位置。嵌入内容通过容器查询按可用宽度切换列数，宽度达到 800px 后恢复桌面排版。背景同步延伸为全屏黑色并保留扫描线。手机端始终使用全屏内容，不显示展开按钮，内容遮罩没有扫描线。

## 路卡头疼模式

在 AnuConsole 的“功能调整 → 首页 → 路卡雕像的头疼模式”切换。状态保存在既有 R2 桶的 `config/home-features.json`，修改配置无需重新部署；接入代码首次上线仍需部署 Worker 和网站。

首页挂载时通过 `/api/site/home-features` 读取配置，与场景模块并行加载。请求超过 2.5 秒、接口失败、响应无效或配置不存在时，均使用普通模式。新打开或刷新首页时生效，已经打开的页面不会轮询配置。开发环境默认直连 `https://steam-api.anuluca.com/site/home-features`，可通过 `VITE_HOME_FEATURES_URL` 覆盖。`templeExperience.headache.mode` 的本地默认值也为 `'normal'`。

运行时模式：

- `'headache'`：默认首页启用后仰歪头与双臂扭曲（身体保持正常），以及头顶半透明实心方块特效。
- `'normal'`：全局恢复正常姿态，不生成头疼姿态和贴纸纹理。

`headLeanBack`、`headTilt`、`bodyTwist`、`upperArmTwist`、`forearmTwist` 分别控制头部后仰增量、头部侧倾、身体、大臂和小臂角度（单位：度），当前为 `29 / 7 / 0 / 12 / -22`。大臂、小臂均绕横向 X 轴前后旋转，双臂使用相同的前后方向。头疼模式反向跟随鼠标，聚焦方尖碑时也不自动朝向柱子；正常姿态保留原有的方尖碑注视逻辑。手臂采用平滑区域权重，配置角度为最大变形角度。

进入 ISLAND 全身预览（`statue`）或创作模块（`island`）时，自动恢复正常姿态并隐藏贴纸；返回默认首页后恢复配置的模式。减少动态效果偏好下直接切换，其余情况下平滑过渡。贴纸颜色滤镜使用降低饱和度与亮度的砖红色 `#a63d32`（模型头部红色仍为 `#ff2020`），不随网站主题变化；特效从模型入场动画开始即渐显，不等待入场结束；隐藏时渐隐，淡出完成后才隐藏对象。特效由不同大小、透明度的实心方块以统一水平角度错位叠加，无描边，并加入使用 `UnboundedSans` 的水平 `ERROR` 文字，随方块随机错位出现，每 100ms 重新随机生成位置、尺寸与透明度（约 10 帧/秒），不循环固定布局；减少动态效果偏好下保持静态布局。静止时仅在重新生成布局时唤醒场景，隐藏或离场后停止播放。

头疼模式的模型本体从可见底部的无饱和度灰色向头顶的红色渐变；在光照后去色，避免主题灯光与环境反射将底部重新染色，并保留明暗和高光层次。染色与头疼姿态同步淡入淡出，恢复正常姿态时移除。倒影沿用模型自身的高度方向。

姿态在场景副本上生成，不修改共享模型缓存；实体、线框、深度和倒影共用姿态权重。

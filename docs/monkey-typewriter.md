# 猴子打字：设计与实现

## 页面设计

- 入口：`/atrium/laboratory` → 猴子打字 → `/laboratory/monkey-typewriter`。
- 公共容器：复用明日方舟的 `ReplicaExperimentLayout`，使用 1600 × 912 设计画布、统一等比缩放、移动端旋转、返回入口与 `PageFooter`。
- 视觉：模块背景透明，沿用网站红色主题和表面／输入框／边框／文字全局变量。顶部水平居中放置用户提供的透明猴子打字机照片，首次为 START、生成后为 RESTART；按钮位于图片内部底部，水平居中，使用正常矩形，不设置旋转、斜切或杯子遮挡层，字体为 `alibaba-puhuiti`、900 字重，无下划线；图片右上方为巴别图书馆入口。
- 布局：图片下方为标题与正文编辑区；操作栏左侧为复制全文、下载 .txt、分享，右侧为保存至巴别图书馆。
- 图片：使用本地 R2 的 `media-tool/素材处理.mjs`（WebP 质量 80）压缩后上传线上桶，保留原尺寸与透明通道；页面使用线上 `20261109_140508_typewriter.webp`、`20261109_171447_babel-library.webp`，封面使用 `20261109_135158_cover.webp`。三图合计从 6.62 MiB 降至约 473 KiB，原件由脚本归档。
- 操作：随机生成草稿、编辑生成稿的标题与正文、跳过出字、主动保存、图片分享、复制全文、下载文本、巴别图书馆、重读档案、刷新与继续加载。
- 动效：仅保留出字效果；尊重减少动态效果偏好（`prefers-reduced-motion`）。
- 图书馆是已经生成文章的有限集合，不声称收录所有可能的文本。
- 隐藏手稿编号、草稿状态、日期、字数与底部提示。空状态仅显示“点击‘开始打字’，生成一篇随机文章”，字体为 alibaba-puhuiti、900 字重。
- 按钮复用相册控件混入；Element Plus 图标位于文字左侧，无分享箭头或渐变。保存和图书馆入口红底，其余透明底红框；悬停青色。点击复用 flashActionButton，青色闪烁两次完成后再执行回调，闪烁中拦截重复点击，组件离场取消待执行操作。减少动态效果时沿用工具函数的即时执行规则。

## 实现方案评估

| 方案 | 结果 |
| --- | --- |
| 浏览器本地保存 | 无法提供跨访客共享图书馆，排除 |
| 语言模型生成 | 不符合随机字母实验，增加调用成本，排除 |
| 新增数据库／全局协调对象 | 当前只需不可变正文与分页列表，暂不引入 |
| 现有 Worker + R2 | 复用存储、管理密钥与部署流程；采用 |

- 服务端使用 Web Crypto 随机数，以拒绝采样避免取模偏差；随机决定词长、字母、句长及结尾标点，不使用词库、语料或语言模型。
- 每篇四段，每段三句，每句 10–20 个随机单词，每词 1–10 个字母；可能偶然出现真实英文单词。
- 固定段落与句式结构只负责可读排版；正文和随机标题均来自本次随机敲击。
- 随机生成仅返回草稿，不写入 R2。生成后的标题和正文可直接编辑，已移除空白手稿入口；点击“保存至巴别图书馆”后才公开入库，保存失败保留草稿。
- 已保存文章再次编辑时，使用新标识另存一篇；不覆盖共享档案原文。保存状态以标题与正文快照判断，未修改时不重复保存。

## 存储与接口

- 绑定：既有 `FLORATRIUM_BUCKET`，桶 `anutrium`。
- 对象键：`monkey-articles/{id}.json`。
- ID：`13 位逆毫秒时间戳-UUID v4`，用于 R2 字典序倒序分页；新请求时间必须处于服务端时间 ±5 分钟。
- 正文、标题、创建时间、字数、字符数、预览摘要保存在同一 JSON；R2 自定义元数据保留列表摘要。
- 客户端失败后重用同一请求 ID。`If-None-Match: *` 条件写入保证并发重试只保存一次；已存在档案直接返回原文。
- 每页 20 个对象，通过游标继续读取；不遍历全部正文，不创建易丢更新的共享索引文件。

| 接口 | 权限／行为 |
| --- | --- |
| `GET /monkey-articles?cursor=...` | 公开分页摘要 |
| `POST /monkey-articles/generate` | 允许来源 + `{}` JSON 请求；只生成草稿，不写入存储 |
| `POST /monkey-articles` | 允许来源 + JSON 请求；接受 `{ id, title, content }`，主动保存纯文本 |
| `GET /monkey-articles/{id}` | 公开读取全文 |
| `GET /admin/monkey-articles` | 管理密钥；供 AnuConsole 服务端代理 |
| `GET /admin/monkey-articles/{id}` | 管理密钥；返回原始版本标识 |
| `DELETE /admin/monkey-articles/{id}` | 管理密钥 + `If-Match`；条件写入删除标记 |

- 删除标记不会出现在公开列表与详情中；保留标识以阻止旧请求重试使文章复活。已存档正文不可原位覆盖，同一标识携带不同内容时返回 409。
- 原始版本通过 `X-Article-Version` 传递，后台优先使用该值，避免 CDN 压缩产生的弱 ETag 导致合法删除失败。
- 公开生成与保存共用限流：`MONKEY_CREATE_LIMITER`，5 次／60 秒／可信边缘 IP；这是 Cloudflare 节点内尽力限流，不是全球严格额度。
- 浏览器直接请求 Worker，避免代理把不同访客合并到同一 IP 额度；不存储或公开访客 IP。
- JSON 请求实际字节上限为 64000，标题最多 120 字符、正文最多 12000 字符；拒绝空内容和非法控制字符。游标上限 2048 字符。前后台均按纯文本展示，不解释 HTML。错误不泄露管理密钥或上游诊断信息。

## 分享

- 点击底部“分享”即分享 PNG，旧的文字／图片选择菜单和二次确认按钮已移除，不隐式保存或上传草稿。
- 分享图复用当前页面元素与字体、边框、扫描线、文章高亮及分析内容；在离屏副本中完整展开正文，去掉 RESTART／SKIP、底部操作栏和书架，猴子图片独立水平居中。
- 底部左侧显示工具页面链接 `https://anuluca.com/laboratory/monkey-typewriter`，右侧放置同一链接的标准二维码（M 纠错、4 模块留白）。二维码在本地生成，不访问第三方二维码服务。
- 使用已有 html-to-image 渲染页面副本；替换跨域污染的动画 canvas 为嵌入后的原图，保留扫描线和渐隐；仅嵌入当前文字实际使用的字体分片，避免加载完整字库。输出 PNG 宽 1200px，全文按内容增高，过长时明确报错，不裁切正文。
- 页面正文、滚动位置及正常布局不变；离屏副本设置 inert 并在 finally 中移除，冻结样式后移除业务类名，避免页面查询命中副本。
- 正文或分析变化后预生成并缓存 File，原生分享在点击事件中直接使用已准备文件；分享按钮的闪烁与调用并行以保留用户激活。分析结果使旧副本过期时，同一次点击自动等待最新副本。
- 支持系统文件分享时打开系统分享；用户取消时不下载。浏览器不支持或调用失败时改为下载 PNG，反馈统一使用 ElMessage。临时下载对象 URL 用后释放。
- 新增 qrcode 运行依赖；测试使用 jsqr 与 pngjs 解码真实导出图，校验二维码目标、全文尾部、高亮、控件排除、猴子居中及导出前后页面几何与滚动不变。

## AnuConsole

- 菜单：猴子打字；页面 `/anutrium/monkey-typewriter`。
- 复用 `ManagementButton`、`ManagementModal`、`Pagination` 和后台样式变量。
- 读取执行 `requireUser()`；删除执行 `requireAdmin()`、同源检查与版本检查；只读账号不能调用删除。
- 管理密钥沿用服务端 `HOME_FEATURES_TOKEN`，上游域名沿用 `HOME_FEATURES_URL`，不返回浏览器。
- 支持分页、刷新、全文预览、取消删除及删除确认；所有自动化测试模拟写入，不修改真实 R2。

## 英文单词分析

- 使用 ESDB 2026.02.25 的美式标准词表（size 60），固定上游提交与 SHA-256 校验，筛选后 79,164 条。仅保留上游已有的小写 ASCII 词条且长度至少为 3；词表收录表示拼写有效，不表示常用或上下文有意义。
- 资源位于 `src/assets/wordlists/english-words.txt`，版权许可嵌入文件头，完整上游许可保留在同目录 `LICENSE.txt`。运行 `node scripts/build-english-wordlist.mjs` 可重建，日常构建无需联网下载词表。
- 词表约 754 KB，gzip 约 213 KB。Vite 以独立带哈希文本资源输出，不内嵌进 JavaScript 主包；只在猴子打字页挂载时请求，成功后在当前页面会话内缓存 Set，图书馆往返复用。
- 仅分析正文，完整单词匹配、忽略大小写、至少 3 个字母；不从数字混合词、缩写、连字符词或其他语言的连续字串中截取英文子串。复数等已有词形独立统计。
- 按首次出现顺序列出去重单词与重复次数，同时展示去重数量和出现总次数。长列表可横向滚动；无命中时显示明确空状态。
- 生成／读取文章后分析，连续编辑正文采用 300ms 防抖；重新生成时分析框退场，新文章完成后重新分析。词表超时、HTTP 错误或无效内容均可重试，不阻塞正文生成、编辑及保存。

- 本轮验证：类型检查、生产构建、桌面／移动端 26 项测试通过。新增测试使用真实词表验证词边界、大小写、重复次数、正文编辑、存档重算、缓存复用和加载失败重试；构建确认词表以独立哈希资源输出。新增模块通过 ESLint 检查。

- 正文使用不可交互的高亮背景层与原生 textarea 叠放，完整词匹配结果以半透明主题色标记；仍可直接编辑、选择和复制原文。高亮与统计共用词边界规则，以文本节点渲染，滚动／尺寸变化通过既有 useFrameTask 同步，编辑更新后清理旧标记。
- 分析文案统一为“本次生成了 x 个正常单词：”，词语及重复次数紧接冒号显示在同一行；零命中显示“暂无”，长内容横向滚动。
- 分析框通过外层弹性布局在完整 84px 区域内垂直居中，移除原来的单侧顶部间距；手机端布局验证使用画布内部坐标，兼容整体旋转。

## 初始聚焦与开屏

- 初次进入时不展示文字框，图片组合在可用 header 区域水平、垂直居中，放大为正常状态的 1.45 倍，START 继续跟随组合中心。
- 点击 START 即进入工作状态，header 用 640ms 过渡缩小并上移；文字框通过 Vue `crt-effect` Transition 调用与 ModalWrapper 相同的全局 `anutriumCrtOn`（460ms、延迟 180ms）展开，保留 `anutriumCrtOff` 退场规则，不另写近似电视机关键帧。
- 无文章且首次请求未完成时在已展开区域显示生成中状态，失败后保留当前布局以便重试。打开存档后直接进入已展开工作状态；从初始状态访问图书馆再返回仍保留初始聚焦。
- 减少动态效果偏好下 header 与开屏缩短至 180ms。页面边框、按钮显隐、分析区、图书馆往返与全屏离场继续沿用现有组件及规则。

- 初始居中 header 组合放大倍率进一步增至 1.7，保持实际视觉中心；书架标题增加一层黑色柔和字形投影，打字后的组合尺寸不变。

- 修复缩小过程中书架和标题消失：移除书架入口受 `busy`／`saving` 控制的 `v-show`，请求期间仅禁用点击，不卸载或隐藏图片。缩小上移动画保持 1280ms；慢于动画的 1800ms 生成请求回归逐帧验证图片、标题持续可见及中间缩放尺寸。

- 主按钮复用同一 DOM 元素：空白时 START，生成／打字期间 SKIP，完成后 RESTART；下方跳过按钮已移除。SKIP 立即结束打字动画，不等待按钮闪烁，避免打字恰好结束时误触下一次生成。请求尚未返回时点击 SKIP 会记录意图，响应返回后直接显示全文，不追加生成请求。

- 保存按钮改用 Element Plus Upload 图标；底部操作按钮入场在 480ms 内向上移动 12px 并渐显，退场沿用透明度过渡，不改变操作行占位。减少动态效果偏好下仅淡入。

- 页面图片分享验证：类型检查、生产构建、分享工具 ESLint 及桌面／移动端 36 项回归通过。实际 PNG 的二维码使用独立解码器识别为正式页面链接；导出正文包含完整尾部，原页面滚动与尺寸保持不变。
